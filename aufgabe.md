Задачи по приоритету:

1. Security Rules в Firestore (КРИТИЧНО, 1 час)
   Проверить текущие правила в Firebase Console → Firestore → Rules
   Переписать так: рабочий читает/пишет только свои часы и свои фото; шеф (роль admin) читает/пишет всё; неавторизованные — ничего
   Протестировать через Rules Playground
2. Budget Alert в Google Cloud (5 минут)
   Google Cloud Console → Billing → Budgets & alerts → €5/месяц, алерты на 50/90/100%
3. Сжатие фото перед загрузкой в Storage (2-3 часа)
   Установить browser-image-compression
   Перед uploadBytes сжимать фото до ~500KB, максимальная сторона 1920px
   Показывать прогресс загрузки
4. Экспорт отчёта в Excel (3-4 часа)
   Установить xlsx
   На странице шефа кнопка "Экспорт за месяц" с выбором месяца
   Excel со столбцами: Имя рабочего, Объект, Дата, Часы, Всего за период
   Имя файла: Отчёт*<месяц>*<год>.xlsx
5. Дашборд для шефа (4-6 часов)
   Главный экран при входе шефа
   Карточки сверху: "Работают сейчас: N", "Часов за неделю: N", "Активных объектов: N", "Всего рабочих: N"
   График часов по дням за последние 30 дней (использовать recharts, BarChart)
   График часов по рабочим за текущий месяц (PieChart или BarChart)
   Данные брать через onSnapshot для real-time обновления
6. Полировка UX (2-3 часа)
   Confirm-диалоги перед удалением (объекта, юзера, записи времени)
   Спиннеры при загрузке данных и фото
   Toast-уведомления об успехе/ошибке действий
   Empty states ("Нет данных" вместо пустого экрана)
7. Демо-данные для презентации (1 час)
   Создать 4 тестовых рабочих с реальными именами
   5 объектов с адресами
   Заполнить часами за последние 2-3 недели
   Загрузить несколько фото задач
   Требования к коду:
   TypeScript strict, без any
   Все тексты UI на русском
   Валюта — евро (€), формат 1 234,56 €
   styled-components для стилей, без inline-стилей
   Обработка ошибок Firebase с понятными сообщениями юзеру
   Не ломать существующий функционал — сначала смотреть код, потом править
   Порядок выполнения строго по приоритету 1→7. После каждой задачи — короткий отчёт что сделано и где могут быть проблемы
